Same scientific runtime

The Windows installer does not replace SageMath, PARI/eclib, or Rank Hunter's scientific subprocesses with separate Windows implementations. It manages an Ubuntu environment under WSL2 so Windows and Linux users run the same research stack.

Ubuntu / Linux

Install directly in three steps.

The source installer stays inside the checkout and is safe to rerun when refreshing or repairing the local environment.

01

Clone Rank Hunter

git clone https://github.com/crhillresearch/rank-hunter.git rank-hunter
cd rank-hunter
02

Run the installer

bash install.sh

Initializes native vendor submodules, installs UI/scientific runtime pieces, creates or migrates the local database, builds and smoke-tests CPU ratpoints, attempts the GPU build when CUDA is available, and installs the public plugin checkout.

03

Start Rank Hunter

bash scripts/run-ui.sh

Rank Hunter opens or creates its local rank42.db. Research databases and backups are local scientific state and are not part of the source release.

Already manage the native tools?

Use Lite mode.

If you already have working CPU/GPU ratpoints executables and want Rank Hunter to preserve those configured paths, Lite mode skips native vendor compilation.

Lite install 
bash install.sh --lite

What gets installed

A local research workstation.

Local scientific state

SQLite stores curves, exact points, rank evidence, jobs, lattices, quartic searches, provenance, and reproducibility metadata.

Public plugins

The public plugin collection keeps Family mathematics and Workspace tools separate from Rank Hunter core.

CPU / GPU point search

CPU ratpoints is the normal path; GPU acceleration is attempted only when a compatible CUDA environment is available.

One evidence standard

Windows or Linux changes how Rank Hunter starts, not what it is allowed to claim mathematically.
