The basic idea

Simple design.
Serious math.

Rank Hunter does not hide the evidence model, but it does hide unnecessary plumbing. A researcher can move from a promising family specialization to exact points, rigorous lower bounds, descent, geometry, and reproducible history without stitching together a pile of disconnected one-off scripts.

03

Prove

Make the evidence climb before the claim does.

Rank Hunter separates exact points, rigorous independence, lower bounds, upper bounds, saturation, and exact rank so that a promising computation never quietly becomes a theorem.

Exact Rational point

Verify the coordinates exactly on the stored elliptic curve.

→
Rigorous Independent directions

Certify enough independent points to establish a lower bound.

→
Rigorous Upper bound

Use supported descent/rank-bound engines under explicit time limits.

→
Proof Exact rank

Record exact rank only when rigorous lower and upper bounds meet.

Scientific boundary: heuristic signals schedule work; exact point verification establishes a point; Independence can raise the rigorous lower bound; Descent can establish a rigorous upper; conditional analytic bounds remain conditional; timeouts and failed engines remain inconclusive.
Independence

Exact directions, not just lots of points

Resolve point dependence and certify new Mordell–Weil directions before increasing a rigorous lower bound.

Descent

Close the rigorous rank interval

Run bounded rigorous rank-bound methods, inspect structured engine evidence, escalate when stronger budgets are justified, and attempt exact-rank certification only when the current evidence supports it.

Saturation

Track subgroup index without inventing rank

Record bounded saturation evidence separately. A nontrivial saturation index changes subgroup index/basis, not rank.

L

Libraries

Think of Libraries as the clean room for everything accumulated outside Rank Hunter: old certs, spreadsheets, exported curve sets, source artifacts, historical observations, aliases, mapped fields, and provenance. Original files remain external research material. You can preview, map, project, search, compare, build Candidate Pools, or explicitly validate mapped points without silently promoting external rank claims into authoritative evidence.

C

Catalogs

Keep external reference sources such as ICARM or LMFDB distinct from evidence Rank Hunter has actually reproduced in your local research state.
