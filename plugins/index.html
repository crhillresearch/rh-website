Scientific boundary

Plugin metadata is not a shortcut around proof.

A literature theorem, a generic rank statement, a specialized exact rank, and a heuristic search score are different claims. Rank Hunter keeps them different too. Each plugin's own README/provenance documents what it actually establishes.
